余额数据源 · 已解决，无需 API key

DSH 的账号控制器本身就提供余额查询，插件通过 ctx.remote.account.getBalance({ version, locale, timezoneOffsetSeconds }) 读取， 和「设置 → 账户」显示的是同一个数。
返回结构：{ ok, value: { value: [...充值钱包], bonusWallets: [...赠送钱包] } }。 多钱包按币种累加，优先显示 CNY；金额格式对齐 Platform Web（两位小数、千分位、次分级显示 <¥0.01）。
因此不需要 sk- 开头的 API key，也不需要你提供任何凭证。
